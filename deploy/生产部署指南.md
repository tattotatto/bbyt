# HXMall 生产服务器部署指南

> 适用：正式上线 `baby.mx.yn.cn`（真实域名 + HTTPS + 真实微信登录）。
> 若只是内网联调，参照 `deploy/deploy.py` / 内网步骤即可（可跳过 HTTPS 与微信合法域名）。

## 部署架构

```
微信小程序/浏览器 → https://baby.mx.yn.cn → Nginx(443) → hxmall-api-1(:7000)
                                                    ├ /admin        → admin SPA（构建 base=/admin/）
                                                    ├ /api/v1/*     → FastAPI
                                                    ├ /api/v1/ai/ws → WebSocket
                                                    ├ hxmall-db-1   (pgvector，内部，不对外端口)
                                                    └ hxmall-redis-1(内部)
```

## 第 0 步 · 前置准备

| 项 | 要求 |
|----|------|
| 服务器 | Ubuntu 22.04+，4核8G+，50G+；Docker + Docker Compose v2 |
| 域名 | `baby.mx.yn.cn` 与 `wss://baby.mx.yn.cn` A 记录指向生产服务器 IP |
| 微信 | 已认证小程序，拿到 `appid`/`secret` |
| SSH | 用密钥登录（生产**禁用密码**，勿把密码写进脚本） |
| 代码 | 本机 git `master` 已含全部修复（admin base=/admin、307 路由、bcrypt 4.0.1、昵称展示） |

## 第 1 步 · 本机构建

```bash
cd admin && npm install && npm run build          # base 已是 /admin/
rm -rf ../backend/admin-dist && mkdir -p ../backend/admin-dist
cp -r dist/* ../backend/admin-dist/
cd ../backend && docker build -t hxmall-api:latest .
```
> `.dockerignore` 已排除密钥/缓存。生产密钥**不打进镜像**，走 compose 环境变量注入。

## 第 2 步 · 生产配置

从 `deploy/.env.example` 复制为 `deploy/.env.production`，填真实值：
```ini
JWT_SECRET_KEY=<openssl rand -hex 32 生成>
WECHAT_APPID=<appid>
WECHAT_SECRET=<secret>
DEEPSEEK_API_KEY=...   # 可选
QWEN_API_KEY=...       # 可选
```
> `.env.production` **不要提交 git**。

## 第 3 步 · 部署（一键脚本）

```bash
chmod +x deploy/deploy-prod.sh
./deploy/deploy-prod.sh <生产服务器IP> [SSH用户] [/opt/hxmall]
```
脚本依次：构建 admin → 构建镜像 → 推镜像 → 上传 compose/.env → `up -d` → 迁移 → 建管理员 → 验证。

手动方式见下。

## 第 4 步 · 数据库迁移（关键）

```bash
ssh user@PROD_IP "cd /opt/hxmall && docker compose exec -T api alembic upgrade head"
# 应看到 Running upgrade c3d4e5f6a7b8 -> d4e5f6a7b8c9
```

## 第 5 步 · 初始化管理员

```bash
ssh user@PROD_IP "cd /opt/hxmall && docker compose exec -T api python -" <<'PY'
import asyncio
from app.database import async_session_factory
from app.models.user import User, UserRole, UserStatus, RetailerLevel
from app.services.auth_service import hash_password
from sqlalchemy import select
async def main():
    async with async_session_factory() as s:
        r = await s.execute(select(User).where(User.role==UserRole.ADMIN))
        if r.scalars().first(): print('admin exists')
        else:
            s.add(User(phone='13800000000', hashed_password=hash_password('admin123'),
                       role=UserRole.ADMIN, level=RetailerLevel.NORMAL, status=UserStatus.ACTIVE))
            await s.commit(); print('admin created')
asyncio.run(main())
PY
```

## 第 6 步 · Nginx 反代（服务器已有 nginx，只加 location 块）

> 本部署**只部署 Docker**；域名反代用你现有 nginx，无需新建容器。

1. 打开你现有 nginx 的 `server` 块（处理 `baby.mx.yn.cn` 的那个）
2. 把 `deploy/nginx-prod.conf` 中的 **① location 片段** 粘贴进该 server 块
3. 确认后端容器已把 7000 发布到宿主机（compose 已配 `7000:7000`）→ nginx 反代到 `127.0.0.1:7000`
   - 若你的 nginx 是**容器**运行：把 `proxy_pass` 改成 `http://host.docker.internal:7000`，并给 nginx 容器加 `extra_hosts: host.docker.internal:host-gateway`
4. `nginx -t && nginx -s reload`
5. 验证 `https://baby.mx.yn.cn/api/v1/health` 与 `/admin/`

## 第 7 步 · 全链路验证

| 检查 | 命令 |
|------|------|
| 健康 | `curl https://baby.mx.yn.cn/api/v1/health` → `db:ok redis:ok` |
| 后台 | 浏览器 `https://baby.mx.yn.cn/admin/`，管理员登录 |
| 微信登录 | 小程序点登录，确认拿到真实 openid（非 dev_ 模式）|
| 主链路 | 浏览→详情→加购→下单→订单操作 |

## 第 8 步 · 小程序发布

1. `cd miniapp && npm install && npm run build:mp-weixin`
2. 微信开发者工具导入 `dist/build/mp-weixin` → 上传
3. mp 后台配置合法域名：request `https://baby.mx.yn.cn`，socket `wss://baby.mx.yn.cn`
4. 提交审核 → 发布

## 常见问题

- **后台空白**：确认 admin 构建 base 是 `/admin/`（vite.config.ts），资源路径应含 `/admin/assets/`；浏览器强制刷新。
- **接口 307**：本仓库已补齐所有无斜杠路由变体；若新增路由，跑 `tests/test_route_slash.py` 防止回归。
- **微信登录不进**：检查 `.env` 的 `WECHAT_APPID/SECRET` 是否为空（空 = 开发模式），compose 是否注入。
- **bcrypt 告警**：`requirements.txt` 已锁 `bcrypt==4.0.1`。
