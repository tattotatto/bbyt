部署架构

微信小程序/浏览器 → https://baby.mx.yn.cn → Nginx(443) → hxmall-api-1(:7000) ├ /admin → admin SPA（构建 base=/admin/） ├ /api/v1/* → FastAPI ├ /api/v1/ai/ws → WebSocket ├ hxmall-db-1 (pgvector，内部，不对外端口) └ hxmall-redis-1(内部)

只部署 Docker现有 Nginx 反代

1 获取代码 + 本机构建

# 1) 获取最新代码（首次克隆；已有则拉取 master，须含全部修复提交）
git clone <你的仓库地址> hxmall && cd hxmall      # 首次部署
git checkout master && git pull                  # 已有代码时更新
git log --oneline -3                             # 确认有 fix(api)/docs(deploy) 等提交

# 2) 构建管理后台（base 已是 /admin/）
cd admin && npm install && npm run build
rm -rf ../backend/admin-dist && mkdir -p ../backend/admin-dist
cp -r dist/* ../backend/admin-dist/

# 3) 构建后端镜像
cd ../backend && docker build -t hxmall-api:latest .
.dockerignore 已排除密钥/缓存。生产密钥不打进镜像，走 compose 环境变量注入。

2 生产配置

从 deploy/.env.example 复制为 deploy/.env.production，填真实值：

JWT_SECRET_KEY=<openssl rand -hex 32 生成>
WECHAT_APPID=<appid>
WECHAT_SECRET=<secret>
DEEPSEEK_API_KEY=...   # 可选

.env.production 不要提交 git。

3 部署（一键脚本）

chmod +x deploy/deploy-prod.sh
./deploy/deploy-prod.sh <生产服务器IP> [SSH用户] [/opt/hxmall]

脚本依次：构建 admin → 构建镜像 → 推镜像 → 上传 compose/.env → up -d → 迁移 → 建管理员 → 验证。

6 Nginx 反代（现有 nginx 只加 location 块）

本部署只部署 Docker；域名反代用你现有 nginx，无需新建容器。
  1. 打开你现有 nginx 的 server 块（处理 baby.mx.yn.cn 的那个）
  2. 把 deploy/nginx-prod.conf 中的 ① location 片段 粘贴进该 server 块
  3. 确认后端容器已把 7000 发布到宿主机（compose 已配 7000:7000）→ nginx 反代到 127.0.0.1:7000
  4. 若你的 nginx 是容器运行：把 proxy_pass 改成 http://host.docker.internal:7000，并给 nginx 容器加 extra_hosts: host.docker.internal:host-gateway
  5. nginx -t && nginx -s reload
  6. 验证 https://baby.mx.yn.cn/api/v1/health 与 /admin/

安全清单

  • SSH 密钥登录，禁用密码
  • JWT_SECRET_KEY 用 openssl rand -hex 32 生成
  • 数据库密码改强（compose 里 postgres/postgres），db/redis 用 expose 不对外
  • 管理员初始密码 admin123 上线后立即改
  • 微信 secret 只在服务器 .env，不进 git/镜像
  • 定期备份 pgdata volume 与 uploads/
  • 监控 docker compose logs -f api、磁盘、容器健康

常见问题

后台空白：确认 admin 构建 base 是 /admin/（vite.config.ts），资源路径应含 /admin/assets/；浏览器强制刷新。

接口 307：本仓库已补齐所有无斜杠路由变体；若新增路由，跑 tests/test_route_slash.py 防止回归。

微信登录不进：检查 .env 的 WECHAT_APPID/SECRET 是否为空（空 = 开发模式），compose 是否注入。

bcrypt 告警：requirements.txt 已锁 bcrypt==4.0.1。
